Method and provenance

Model {{ model_version }}. The generator parses stored SMILES first and falls back to standard InChI when RDKit rejects the stored SMILES. This build used that fallback for {{ quality.inchi_fallback_count }} records and retained {{ quality.multifragment_count }} multi-fragment records. All {{ quality.stereoisomer_pair_count }} detected stereoisomer pairs have nonzero model distance.

Distance is 90% radius-2 and 10% radius-4 chiral Morgan count-fingerprint Tanimoto distance. Coordinates are generated with UMAP(metric=precomputed, n_neighbors=15, min_dist=0.05, random_state=42). A corpus or model-version change can move every point.
